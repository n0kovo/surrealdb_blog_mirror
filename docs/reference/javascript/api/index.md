# API reference

Reference documentation for every public class, type, and helper in the JavaScript SDK. For task-oriented guidance, see the [concepts](../concepts/connecting-to-surrealdb.md) pages.

## Sections

- [**Core classes**](core/index.md) - Connecting, sessions, transactions, and query execution.
- [**Query builders**](queries/index.md) - The chainable builders returned by each query method.
- [**Data types**](values/index.md) - Classes for SurrealDB-specific values such as `RecordId` and `Duration`.
- [**Utilities**](utilities/surql.md) - Helpers for building parameterised queries and comparing values.
- [**Errors**](errors/index.md) - Error classes raised by the SDK.
- [**TypeScript types**](types/index.md) - Type definitions and interfaces used throughout the SDK.
